## 第 5 页：生成流程 — 以椭圆焦点弦为例

**页面内容：** 左侧六步生成算法（参数选取→几何构造→联立消元→判别式验证→韦达定理→计算结果）；右侧可解性保证和核心代码。

**讲稿：**

以椭圆焦点弦为例，看题目的生成流程。

第一步，参数选取。从 {2,3,4,5,6} 中随机选 a、b，计算 c 和 e。第二步，几何构造。过左焦点 F₁ 斜率为 k 的直线方程是 y = k(x+c)。第三步，联立消元。代入椭圆方程得到二次方程。第四步，判别式验证。确保 Δ ≥ 0，有实交点。第五步，韦达定理。求出交点 P、Q 的坐标。第六步，计算弦长和三角形面积。

右侧是核心代码。联立方程系数 A、B、C 的计算，判别式验证，以及交点求解。可解性保证有三点：判别式 Δ ≥ 0 确保有实交点，参数约束确保椭圆 a>b>0，整数优化确保答案简洁。

## 第 6 页：数据模型设计

**页面内容：** 左侧 ConicParams 和 Problem 的完整代码；右侧 Point & Line 数据结构。

**讲稿：**

首先是数据模型设计。系统的核心是四个数据类：

第一个是 ConicParams，存储圆锥曲线参数。**为什么这样设计？** 因为 c 和 e 在 __post_init__ 中自动计算，椭圆用 c = √(a²-b²)，双曲线用 c = √(a²+b²)，这样避免了手动推导错误。用 dataclass 可以保证类型安全和自动初始化。

第二个是 Problem，存储完整的题目信息。**为什么所有题型都返回 Problem？** 因为统一接口便于扩展——新增题型只需添加函数，不需要修改其他代码。

第三个是 Point，存储二维点坐标和标签，提供距离计算方法。第四个是 Line，存储直线方程 ax+by+c=0 的系数，提供斜率和点到直线距离的计算。

## 第 8 页：具体题型实现

**页面内容：** 左侧椭圆焦点弦核心逻辑代码；右侧 LaTeX 模板生成和 Unicode 转换代码。

**讲稿：**

以椭圆焦点弦为例，看具体题型的实现。

核心逻辑分三步：**第一步，联立方程。** 把直线 y = k(x+c) 代入椭圆方程，得到二次方程的系数 A、B、C。**第二步，验证可解性。** 计算判别式 Δ = B²-4AC，确保 Δ ≥ 0。**第三步，求解交点。** 用韦达定理求出 x1、x2，然后计算弦长 |PQ| 和三角形面积。

LaTeX 模板生成使用 Python 的 f-string 语法，把计算结果嵌入模板中。终端显示时，再通过正则表达式将 LaTeX 转换为 Unicode，实现实时渲染。

## 第 9 页：配图渲染

**页面内容：** 左侧渲染主流程代码和参数方程绘图代码；右侧坐标系自适应代码。

**讲稿：**

接下来看配图渲染的实现。

渲染主流程在 DiagramRenderer.render() 方法中，分六步：确定坐标范围、创建图形、绘制曲线、绘制辅助线、标注关键点、导出 PNG。

曲线绘制使用参数方程。椭圆是 x = a·cosθ, y = b·sinθ，用 1000 个采样点保证平滑。**为什么用参数方程？** 因为它能精确描述曲线形状，不是贝塞尔近似。

坐标系自适应是关键。_get_plot_range() 函数先根据曲线类型计算基础范围，然后遍历所有关键点扩展范围，最后确保正方形比例，这样配图就不会裁剪任何重要元素。

## 第 14 页：AI 辅助实例 — 椭圆焦点弦

**页面内容：** 左侧AI推导过程（6步）；右侧人工验证过程（代入验算→判别式检查→弦长验证→自动测试）。

**讲稿：**

这是一个具体的 AI 辅助实例。人类告诉 AI："生成椭圆焦点弦题，过左焦点斜率为 k 的直线与椭圆交于 P、Q"。

AI 的推导过程是：先写出直线方程 y = k(x+c)，代入椭圆方程，整理得到二次方程，然后用判别式验证，用韦达定理求交点，最后计算弦长和面积。

**重点看验证环节。** 我用 a=5, b=3, k=1 手动验算了 AI 的推导：联立方程系数 A、B、C 是否正确，判别式 Δ 是否非负，弦长公式是否与手算结果一致。验算通过后，再运行测试脚本确认代码可执行。

这个过程体现了人机协作的核心：AI 负责推导和编码的"体力活"，人类负责数学正确性的"把关"。两者缺一不可——没有 AI，60 种题型逐一推导不现实；没有人工验证，数学错误会隐藏在代码中。

前面提到，本项目中真正的智能体角色是由 Claude Code 承担的。这里详细说明它的工作方式。

Claude Code 是 Anthropic 的命令行 AI 编程工具，它的工作模式就是一个完整的智能体循环：

**第一，理解意图。** 我用自然语言描述需求，比如"实现椭圆蒙日圆题型"。Claude Code 能理解这个数学问题的含义。
