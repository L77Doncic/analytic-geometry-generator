核心算法：题目生成

数学推导 → 参数计算 → 可解性验证 → LaTeX 模板

生成流程 — 以椭圆焦点弦为例

六步生成算法

1
参数选取 — 从 {2,3,4,5,6} 随机选 a,b，计算 c=√(a²-b²)，e=c/a
2
几何构造 — 过 F₁(-c,0) 斜率 k 的直线：y=k(x+c)
3
联立消元 — 代入椭圆方程得二次方程
4
判别式验证 — Δ = B²-4AC ≥ 0，确保有实交点
5
韦达定理 — x₁+x₂=-B/A，x₁x₂=C/A，求交点 P,Q
6
计算结果 — 弦长 |PQ|=√(1+k²)·|x₁-x₂|，面积 S=½|x₁y₂-x₂y₁|

可解性保证

  • Δ ≥ 0 确保有实交点
  • 椭圆 a>b>0，双曲线 a,b>0
  • 参数从整数集选取，优先整数解
  • 每种题型均含完整 LaTeX 解答

实现原理：数据模型设计

ConicParams — 圆锥曲线参数

problem_generator.py
@dataclass
class ConicParams:
    """圆锥曲线参数"""
    center: Tuple[float, float] = (0, 0)
    a: float = 1.0  # 半长轴/半实轴
    b: float = 1.0  # 半短轴/半虚轴
    c: float = 0.0  # 半焦距
    e: float = 0.0  # 离心率
    rotation: float = 0.0

    def __post_init__(self):
        # 自动计算 c 和 e
        if self.c == 0:
            self.c = np.sqrt(abs(self.a**2 - self.b**2))
        if self.e == 0 and self.c > 0:
            self.e = self.c / self.a

设计要点

  • 自动推导：c 和 e 在 __post_init__ 中计算，避免手动错误
  • 椭圆：c = √(a²-b²)，e = c/a < 1
  • 双曲线：c = √(a²+b²)，e = c/a > 1
  • 抛物线：a = p/2, b = 0, c = p/2

Point & Line

数据结构
@dataclass
class Point:
    x: float
    y: float
    label: str = ""  # "F_1", "P", etc.

    def distance_to(self, other):
        return np.sqrt((self.x-other.x)**2 +
                       (self.y-other.y)**2)

@dataclass
class Line:
    a: float  # ax + by + c = 0
    b: float
    c: float

    def distance_to_point(self, p):
        return abs(self.a*p.x + self.b*p.y +
                   self.c) / np.sqrt(self.a**2+self.b**2)

椭圆焦点弦 — 核心代码

_ellipse_chord()
def _ellipse_chord(a, b, c, e, params, k):
    F1 = Point(-c, 0, "F_1")
    F2 = Point(c, 0, "F_2")

    # 联立方程系数
    A_coeff = b**2 + a**2 * k**2
    B_coeff = 2 * a**2 * c * k**2
    C_coeff = a**2*c**2*k**2 - a**2*b**2

    # 判别式验证
    disc = B_coeff**2 - 4*A_coeff*C_coeff
    assert disc >= 0, "无实交点"

    # 韦达定理求交点
    x1 = (-B_coeff + np.sqrt(disc))/(2*A_coeff)
    x2 = (-B_coeff - np.sqrt(disc))/(2*A_coeff)
    y1, y2 = k*(x1+c), k*(x2+c)

    # 计算弦长和面积
    P, Q = Point(x1,y1,"P"), Point(x2,y2,"Q")
    chord = P.distance_to(Q)
    area = 0.5*abs(x1*y2 - x2*y1)

    return Problem(
        title=f"椭圆焦点弦 (a={a},b={b},k={k})",
        topic="椭圆", difficulty=2,
        problem_latex=..., solution_latex=...,
        points=[F1, F2, P, Q],
        answer=f"|PQ| = {chord:.4g}"
    )

LaTeX → Unicode 转换

def latex_to_unicode(text):
    # 移除定界符
    text = text.replace("$$", "")
    text = text.replace("$", "")

    # 转换分数
    text = re.sub(
        r'\\frac\{([^}]+)\}\{([^}]+)\}',
        r'\1/\2', text
    )

    # 转换上标
    text = re.sub(
        r'\^\{([^}]+)\}',
        lambda m: _to_superscript(m.group(1)),
        text
    )

    # 替换希腊字母
    for latex, uni in GREEK_MAP.items():
        text = text.replace(latex, uni)

    return text.strip()

def render(self, problem, output_path):
    # 1. 确定坐标范围
    x_range, y_range = self._get_plot_range(problem)

    # 2. 创建图形
    fig, ax = self._setup_figure(x_range, y_range)

    # 3. 绘制曲线
    if problem.conic_type == "ellipse":
        self._plot_ellipse(ax, problem.conic_params)
    elif problem.conic_type == "hyperbola":
        self._plot_hyperbola(ax, problem.conic_params)
    elif problem.conic_type == "parabola":
        self._plot_parabola(ax, problem.conic_params)

    # 4. 绘制辅助线
    for line in problem.lines:
        self._plot_line(ax, line, x_range)

    # 5. 标注关键点
    for point in problem.points:
        self._plot_point(ax, point)

    # 6. 导出 PNG
    fig.savefig(output_path, dpi=150,
                bbox_inches='tight', facecolor='white')

AI 辅助实例 — 椭圆焦点弦

AI 的推导过程

输入："生成椭圆焦点弦题，过左焦点斜率为 k 的直线与椭圆交于 P,Q"

AI 推导:

  1. 直线: y=k(x+c)
  2. 代入椭圆: x²/a² + k²(x+c)²/b² = 1
  3. 整理: (b²+a²k²)x² + 2a²ck²x + (a²c²k²-a²b²) = 0
  4. 判别式: Δ = (2a²ck²)² - 4(b²+a²k²)(a²c²k²-a²b²)
  5. 韦达: x₁+x₂ = -2a²ck²/(b²+a²k²)
  6. 弦长: |PQ| = √(1+k²)·|x₁-x₂|

人工验证过程

1
代入验算 — 取 a=5, b=3, k=1，手算联立方程系数 A, B, C
2
判别式检查 — 确认 Δ ≥ 0，与 AI 结果对比
3
弦长验证 — 手算 |PQ| 与代码输出一致
4
自动测试 — 运行 test_all_types.py 确认可执行

两者缺一不可：没有 AI，60 种题型逐一推导不现实；没有验证，数学错误会隐藏在代码中
